# Job Market & Salary Analysis 📊

##  Project Overview

This project analyzes job market and salary data using Python to identify salary trends, job roles, experience levels, and in-demand skills.

The project focuses on understanding how salary varies across different job roles and experience levels and which skills are commonly required in the job market.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

##  Project Workflow

1. Imported the job market dataset
2. Explored the dataset using Pandas
3. Checked missing values and data types
4. Cleaned and prepared the data
5. Analyzed salary trends
6. Analyzed job roles
7. Compared salary by experience level
8. Analyzed in-demand skills
9. Created visualizations using Matplotlib

- Salary comparison by experience level
